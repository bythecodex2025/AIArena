# AI Arena

하나의 GitHub Pages 저장소에서 AI 코딩 웹게임을 제공합니다.

- `/animal/` — 동물장기 AI 연구실
- `/card/` — ClashCard
- `/clashcard/` — `/card/` 별칭
- `/auction/` — Starlight Auction 공개 경매·세트 수집 AI 게임
- `/racing/` — Vector Racing 15 TPS 도로 센서·차량 제어 AI 게임
- [오목 AI Arena](https://proudius.github.io/gomoku-ai-prototype/) — 15×15 기본 오목·9×9 랜덤 스코어 AI 게임

예제 게임을 추가하거나 검토할 때는 [AIArena 예제 게임 필수 속성](./EXAMPLE_GAME_REQUIREMENTS.md)을 참고하세요.

새 예제 게임 기획: [Starlight Auction](./STARLIGHT_AUCTION_GAME_DESIGN.md) — 크레딧·영향력·컬렉션 점수를 다루는 공개 경매 전략 게임

공개 주소: <https://bythecodex2025.github.io/AIArena/>
